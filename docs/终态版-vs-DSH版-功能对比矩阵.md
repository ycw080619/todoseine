# 终态版 vs DSH 内部版 · 功能对比矩阵

> 用途：说明「为什么开源定稿是这一套」，以及旧 DSH 内部版还留在哪些坑里。
> DSH 内部版指 `C:\Users\ycw\.dsh\dsh_wechat\todoseine` 那份历史拷贝（无任何入口指向，保留仅为参考）。

## 一句话差别

**DSH 版是「一个人用、坏了再改」的脚本集合；终态版是「别人也能装、坏了能查」的产品。** 差别不在功能多少，而在可维护性、数据安全与分发形态。

## 逐项对比

| 维度 | DSH 内部版 | 终态版 | 为什么改 |
|---|---|---|---|
| 界面 | tkinter 控制台 + tkinter 看板 | 单一 PySide6 看板（五页设置 + 托盘） | tkinter 高 DPI 文字裁切、无动画、无材质；两套 GUI 并存维护成本翻倍 |
| 数据目录 | 仓库根目录 `c2t.db` 与 `%USERPROFILE%\Chat2Todo\qq.db` 双份并存 | 唯一业务库 `%USERPROFILE%\Chat2Todo\qq.db` | 双库导致同步写 A 库、看板读 B 库，出现过「待办凭空消失」 |
| 导出链路 | Docker 容器导出 QQ 库 | 内置只读通道 + 官方插件（DPAPI 存口令） | 要求用户装 Docker 才能用，门槛过高；容器内明文落盘还有泄露风险 |
| 采集 | 主要靠导出文件导入 | UIA 主路径 → 备选选择器 → Win11 OCR 三级降级 | 导出文件有延迟；UIA 能实时取，OCR 保底不挑 QQ 版本 |
| 脱敏 | 无（原文直接进归档与 AI） | 双轨：SQLite 存原文，归档 / 看板 / 日志 / 云端 AI 全走脱敏；AI 前二次校验 | 群里有他人隐私，直接发给云端模型是合规风险 |
| 隐私开关 | 无 | 白名单仅影响展示；「白名单群发明文给云端」需单独开关 + 二次确认 | 一个开关包揽两件事，用户无法只放开展示不放开外发 |
| 密钥 | 明文或环境变量 | DPAPI 加密落盘，导出配置不含密钥 | 明文密钥随备份 / 截图泄露的概率太高 |
| 备份 | 手动复制 db 文件 | 每日自动备份 + DPAPI 加密 + 保留期清理 | 手动备份实际上没人做 |
| 回收站 | 无（删了就是删了） | 7 天保留 + 到期自动清理 + 日志 | 误删待办无法挽回 |
| 一键清空 | 无 | `c2t wipe` 覆盖归档/库/备份/回收站/日志/缓存/插件配置，插件本体保留 | 转手 / 重装时需要可信的清空路径 |
| 插件 | 无协议，脚本直接改主仓 | 独立子进程 + manifest 权限声明 + 崩溃计数安全模式 + 一键回滚 | 脚本崩了带崩主程序；改主仓意味着升级即冲突 |
| 转发 | 无 | 半自动转发：默认关闭、预览窗、3 秒倒计时、切窗取消、审计日志 | 全自动发送风险不可控，只做「人确认机器打字」 |
| 桌面联动 | 无 | JSON/ICS 输出 + 127.0.0.1 随机端口 + Host/Origin 校验 + token ACL | 桌面美化工具需要数据源，但不能再开一个任意可读的端口 |
| 运维 | 无 | Hermes：token 轮换、进程巡检、异常重启、每日汇总 | 常驻进程挂了没人知道 |
| 通知 | 无 | 托盘气泡 + 免打扰时段 | 夜间被打扰 |
| 材质 | 无（纯色窗口） | Mica Alt → 亚克力 → 纯色三级降级 | 只用纯色太丑，只写死亚克力在某些机器上全黑 |
| 打包 | 依赖本机 Python 环境 | PyInstaller 单文件 exe + 开机自启 + 桌面快捷方式 | 换台机器就装不起来 |
| 测试 | 0 项自动化测试 | 394 项 pytest（含 11 项子测试） | 改一处不知道会崩哪儿 |
| 文档 | 口口相传 | README + 分层方案 + 架构 + 插件 SDK + 安全策略 + Win11 验收清单 + 本矩阵 | 交接给 AI 或新人都要能接上 |

## 迁移映射（老用户怎么换）

| DSH 版做法 | 终态版做法 |
|---|---|
| 双击 `console.bat` | 双击桌面 `TodoSeine.lnk`（或 `c2t dash`） |
| 仓库根目录 `c2t.db` | 不存在了，统一 `%USERPROFILE%\Chat2Todo\qq.db` |
| Docker 导出 | 控制台「选择 QQ 数据库」→ 口令存 DPAPI → 内置只读通道 |
| 计划任务 `TodoSeineSync` | 可删；终态版靠常驻进程巡检 |
| tkinter 截图确认窗 | Qt 截图确认窗（同一套核心管线） |

## 保留 DSH 版的理由与风险

- **保留理由**：历史代码可作对照；个别老用户习惯 Ctrl+Alt+S 的旧行为。
- **风险**：它仍可能被计划任务或旧快捷方式拉起，写进 `c2t.db` 造成数据错觉。
- **建议**：确认无快捷方式 / 计划任务指向后删除；本仓库已删掉根目录两个 77KB 旧库副本。
