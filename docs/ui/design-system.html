07 中文排版与孤行

text-wrap: pretty / balance · 标点不落行首 · 最小宽度保护

本周需要处理的事情集中在三条线上：报价单要在明天上午十点前发出，三楼的合同条款必须先复核签字页， 供应链那边的对账数据还差一个批次没有回来。以上三件事都涉及对外承诺，建议按这个顺序推进。

段落走 text-wrap: pretty 减少末行孤字；标题走 balance 让两行等长；表格单元格 min-width:3.5em 兜底。

完整标准见 设计规范-组件与交互.md
  1. 01聚焦前后输入框边界尺寸变化 = 0px（脚本断言）
  2. 02打字动画总时长 ≤ 600ms，单字错开 20~40ms（字数 ≤8 时）
  3. 03暗色正文 400 / 标题 550，文本对比度 ≥ 4.5:1
  4. 04拖拽首帧位移延迟 ≤ 1 帧；释放过冲 ≤ 4px
  5. 05Toast 自动消失 2500ms ±100ms，可点 × 立即关闭
  6. 06reduced-motion 下无位移/无模糊，文字直接可见
