# 界面设计规范 · 组件与交互（微明度体系）

> 适用场景：桌面端常驻小窗 / 侧栏看板 / 待办列表类界面（本仓对应 Chat2Todo 看板与设置页的视觉口径）。
> 参考实现：[design-system.html](./design-system.html)（单文件，双击即开，自带明暗切换与全部交互）。
> 截图：[shots/](./shots/)
>
> 四条硬原则：**层次靠微明度、暗色字重减细、数字锁死等宽、拖拽瞬间咬死。**

---

## 1. 设计令牌（Design Tokens）

### 1.1 表面阶梯（Light）

层级只靠明度差，**相邻层 ΔL 控制在 1.5%~2.5%**，不使用粗边框、不使用高对比硬边框。

| 令牌 | 色值 | 明度 L（HSL） | 相对谁 | 差 | 用途 |
|-|-|-|-|-|-|
| `--bg-canvas` | `#F4F5F7` | 96.3% | — | — | 页面底色 |
| `--bg-sunken` | `#EDEFF3` | 94.1% | canvas | −2.2 | 凹陷（**只叠在 canvas 上**） |
| `--surface-1` | `#FAFBFC` | 98.4% | canvas | +2.1 | 面板 Panel |
| `--surface-2` | `#FFFFFF` | 100% | surface-1 | +1.6 | 卡片 Card / 控件底 |
| `--surface-hover` | `#FFFFFF` | 100% | — | 0（只换阴影） | Hover，禁止靠换底色表达 |

**叠放规则（这条不写清就会超差）：** 凹陷只叠在 canvas 上；面板只叠在 canvas 上；卡片只叠在面板上。
**禁止**把 sunken 塞进面板内部（96.3→94.1→98.4 会出现 4.3% 的跳变，一眼看出"两块不同的灰"）。面板内要分区请用 1px 细线 + 留白，不要再降一级底色。

线：`--line-hairline: rgba(17,24,39,.07)`、`--line-soft: rgba(17,24,39,.12)`。
**细线只做分隔，不承担层级**；层级永远由底色差 + 微阴影表达。

阴影：
```
--shadow-1:    0 1px 2px rgba(16,24,40,.05), 0 1px 1px rgba(16,24,40,.03)
--shadow-2:    0 4px 12px rgba(16,24,40,.06), 0 1px 2px rgba(16,24,40,.04)
--shadow-drag: 0 10px 24px rgba(16,24,40,.12), 0 2px 6px rgba(16,24,40,.06)
```

### 1.2 表面阶梯（Dark）

| 令牌 | 色值 | 明度 L（HSL） | 相对谁 | 差 |
|-|-|-|-|-|
| `--bg-canvas` | `#121417` | 8.0% | — | — |
| `--bg-sunken` | `#0E1013` | 6.5% | canvas | −1.6 |
| `--surface-1` | `#171A1E` | 10.4% | canvas | +2.4 |
| `--surface-2` | `#1C2025` | 12.7% | surface-1 | +2.4 |
| `--surface-hover` | `#23272D` | 15.7% | surface-2 | +3.0 |

暗色相邻差略放宽到 2%~3%（仍在上限内）：暗底上人眼对明度变化更迟钝，1%~1.5% 会糊成一片。

线：`rgba(255,255,255,.07)` / `rgba(255,255,255,.12)`。

### 1.3 文本与对比度（实测值，WCAG 2.1）

| 角色 | Light | 对比度 | Dark | 对比度 |
|-|-|-|-|-|
| 正文 primary | `#15181D` | **16.31:1** | `#E7E9EC` | **14.35:1** |
| 次要 secondary | `#4B525C` | **7.24:1** | `#A9AFB8` | **7.91:1** |
| 说明 tertiary（最差场景） | `#666D77` | **4.54:1**（在 sunken 上） | `#878E98` | **4.54:1**（在 surface-3 上） |

> 三级文本原来用 `#6B7280`，在 canvas 上只有 4.43:1（不达 AA），已下调到 `#666D77`（4.54~5.23，全场景 ≥4.5）。**验收时必须按"最差底色"计算，而不是按白底。**

### 1.4 主色（低饱和，只做标记与聚焦）

| 令牌 | Light | Dark | 说明 |
|-|-|-|-|
| `--accent` | `#4E8C76` | `#6FA893` | 聚焦内环、圆点、选中标记 |
| `--accent-ink` | `#2F6A57` | `#8FC5B1` | 可读的主色文字（5.80:1 / 6.40:1） |
| `--accent-soft` | `rgba(78,140,118,.10)` | `rgba(111,168,147,.12)` | 标签底、幽灵按钮 hover |
| `--accent-glow` | `rgba(78,140,118,.22)` | `rgba(111,168,147,.26)` | 聚焦外环柔光 |
| 主按钮文字 | `#FFFFFF` on `#2F6A57` = 6.33:1 | `#0B0F0D` on `#6FA893` = 7.07:1 | 主按钮不铺大面积饱和色 |

### 1.5 字重与字号

| 令牌 | Light | Dark | 依据 |
|-|-|-|-|
| `--fw-body` | 500 | **400** | 暗底细笔画不向外溢光，长夜阅读眼压更低 |
| `--fw-caption` | 500 | **400** | 同上 |
| `--fw-title` | 600 | **550**（硬上限 600） | 暗色标题再粗会显"糊" |

字号：12 / 13 / 14 / 15 / 17 / 22，正文行高 1.5，标题 1.25。
暗色额外 `letter-spacing: +0.01em`，补偿细字重的视觉收紧。

### 1.6 动效令牌

| 令牌 | 值 | 用途 |
|-|-|-|
| `--dur-hover` | 120ms | 悬停底色/边框 |
| `--dur-focus` | 160ms | 聚焦双环（要求区间 120~180ms） |
| `--dur-press` | 200ms | 按压缩放 |
| `--dur-spring` | 420ms | 拖拽释放回弹 |
| `--dur-toast` | 2500ms | 提示自动消失 |
| `--ease-std` | `cubic-bezier(.22,.61,.36,1)` | 通用 |
| `--ease-press` | `cubic-bezier(.2,.9,.25,1)` | 按下即走 |
| `--ease-spring` | `cubic-bezier(.34,1.4,.64,1)` | 回弹（过冲量靠位移钳制，不靠曲线） |

圆角 8 / 12 / 16；间距 4 / 8 / 12 / 16 / 24 / 32 / 48。

## 2. 组件状态规范

### 2.1 按钮

| 状态 | 底色 | 边框 | 阴影 | 位移/缩放 |
|-|-|-|-|-|
| Rest | surface-2 | 1px hairline | shadow-1 | 无 |
| Hover | surface-hover | 1px line-soft | shadow-2 | 无 |
| Active | 同 Hover | 同 Hover | shadow-1 | `scale(.985)`，200ms |
| Focus-visible | 不变 | 不变 | 内环 1px accent + 外环 4px glow | 无 |
| Disabled | surface-2 | hairline | 无 | `opacity .45`，`cursor:not-allowed` |

主按钮 hover 只 `filter: brightness(1.04)`，**不换色**——换色会让整块色面"跳"。

### 2.2 输入框（双环咬合）

```
Rest   : border 1px hairline, box-shadow: 0 0 0 1px transparent, 0 0 0 4px transparent
Hover  : border-color → line-soft
Focus  : border-color → transparent（让位，避免 2px 叠加显硬）
         box-shadow: 0 0 0 1px var(--accent),   ← 内环 1px，低饱和
                     0 0 0 4px var(--accent-glow) ← 外环 4px 柔光扩散
Error  : 内环 rgba(178,72,60,.65)，外环 4px rgba(178,72,60,.16)（色相只偏心 6%）
Disabled: 底色 sunken，阴影清零，文字 tertiary
```

三条不可退让的约束：
1. 边框宽度恒定 1px，聚焦只改颜色 → **聚焦前后 `getBoundingClientRect()` 宽高完全一致**；
2. 外环必须是 `box-shadow`，不能是 `outline` + `outline-offset`（后者会撑出可点击外沿并影响 `overflow` 裁切）；
3. 静止态就要把两层环声明为 `transparent`，否则首帧聚焦会"闪一下"再出现。

### 2.3 卡片 / 面板

- 面板：surface-1 + 1px hairline + shadow-1 + 16px 圆角。
- 卡片：surface-2 + **无边框** + shadow-1 + 12px 圆角（只靠 1.6% 明度差和阴影分层）。
- 凹陷：sunken，无阴影，圆角 12，**只直接叠在 canvas 上**；叠进面板会出现 4.3% 的跳变，禁用。
- 禁止：卡片之间用 2px 深色边框、用 `box-shadow` 做"发光描边"、给所有层加同样的阴影。

### 2.4 列表项（可拖拽）

| 状态 | 表现 |
|-|-|
| Idle | surface-2 + hairline + shadow-1，`cursor:grab` |
| Press/Drag | `shadow-drag` 抬起、`z-index:3`、`cursor:grabbing`、**transition 全部禁用** |
| 兄弟项让位 | `translateY(±步距)`，420ms spring 缓动 |
| 释放落位 | DOM 立即重排；仅"残留位移"走 420ms 回弹，过冲 2px |
| 减少动态 | 直接落位，不位移不模糊，Toast 直接淡出 |

## 3. CSS / JS 实现要点

### 3.1 双环聚焦（可直接抄）

```css
.field{
  border:1px solid var(--line-hairline);
  border-radius:8px;
  box-shadow:0 0 0 1px transparent, 0 0 0 4px transparent; /* 占位，消除首帧闪烁 */
  transition:border-color 160ms cubic-bezier(.22,.61,.36,1),
             box-shadow   160ms cubic-bezier(.22,.61,.36,1);
}
.field:focus-within{
  border-color:transparent;
  box-shadow:0 0 0 1px var(--accent), 0 0 0 4px var(--accent-glow);
}
```

### 3.2 逐字模糊渐显

预算分配（**总时长硬上限 600ms**）：

```js
const CHAR_MS = 320, BUDGET = 600;            // 单字时长 / 整段上限
const n = chars.length;
const stagger = n < 2 ? 0 : Math.min(40, Math.max(6, (BUDGET - CHAR_MS) / (n - 1)));
// 8 字以内：stagger 落在 20~40ms 区间，总时长 ≤ 600ms
// 更长文本：stagger 自动压缩到 6ms 下限，单字时长不变 → 总时长仍 ≤ 600ms
```

```css
@keyframes char-in{
  from{ opacity:0; filter:blur(5px); transform:translateY(2px); }
  to  { opacity:1; filter:blur(0);   transform:translateY(0); }
}
.ch{ display:inline-block; animation:char-in 320ms var(--ease-std) both; animation-delay:var(--ch-delay); }
```

防抖动三条：
- 行高写死（`line-height:26px`），`min-height` 兜底，动画期间不参与重排；
- 图标用 `flex + align-items:baseline`，图标本身**不参与动画**，只做 `translateY(-1px)` 的静态基线补偿；
- 只在 `span` 上做 `filter/opacity/transform`，父容器不加 `will-change`（否则整段被提升成合成层，反而糊）。

### 3.3 等宽数字

```css
.num, .tick{ font-variant-numeric:tabular-nums; font-feature-settings:"tnum" 1,"lnum" 1; }
.kpi .v{ font-size:26px; font-variant-numeric:tabular-nums; }  /* 计时器每位宽度固定 */
```

要点：数字列一律 `text-align:right` + `tabular-nums`，否则 1111 与 8888 宽度不同会让整列"呼吸"；`min-width:3.5em` 给中文单元格兜底，避免单字孤行。

### 3.4 中文排版

```css
.cn-prose{ max-width:38em; word-break:normal; line-break:strict;
           overflow-wrap:break-word; hanging-punctuation:allow-end; text-spacing-trim:space-first; }
h1,h2,h3{ text-wrap:balance; }   /* 标题两行等长 */
p{ text-wrap:pretty; }           /* 正文末行不留单字 */
```

`hanging-punctuation` 与 `text-spacing-trim` 是渐进增强，不支持时表现等同于普通排版，不产生回退故障。

### 3.5 拖拽（咬死 + 弹簧回弹）

```js
// 1) 按下即咬死：立刻记录基准，拖动期间列表禁用 transition
list.dataset.dragging = "on";          // CSS: [data-dragging="on"] .item{transition:none}
item.dataset.drag = "active";
item.setPointerCapture(e.pointerId);

// 2) 跟手：同一个 pointermove 里直接写 transform，不做 rAF 节流（否则会粘滞）
item.style.transform = `translate3d(0,${dy}px,0)`;

// 3) 目标位：四舍五入到最近槽位，只换兄弟项位移，不重排 DOM（避免逐帧重排抖动）
const target = clamp(idx + Math.round(dy / step));

// 4) 释放：DOM 立即落位，仅让"残留位移"走回弹，过冲钳在 2px
const residual = dy - (target - idx) * step;
item.animate([
  { transform:`translate3d(0,${residual}px,0)` },
  { transform:`translate3d(0,${residual > 0 ? -2 : 2}px,0)`, offset:.62 },
  { transform:"translate3d(0,0,0)" }
], { duration:420, easing:"cubic-bezier(.2,.8,.3,1)" });
```

为什么不用 `cubic-bezier` 的过冲来表现"Q 弹"：曲线过冲量随位移量放大，长距离拖动会冲出十几像素。**过冲必须由关键帧位移钳死（≤4px，实现取 2px）。**

### 3.6 降级

```css
@media (prefers-reduced-motion: reduce){
  *{ animation-duration:1ms !important; animation-delay:0ms !important;
     transition-duration:1ms !important; }
  .ch{ opacity:1; filter:none; transform:none; }
  .toast.out{ transform:none; }
}
[data-motion="off"] *{ animation:none !important; transition:none !important; }  /* 手写开关，供验收 */
```

降级语义：**不是变慢，是直接到达终态**——文字立刻完整可读，拖拽直接落位，Toast 立即淡出。

## 4. 验收清单

| # | 项目 | 验收方法 | 通过标准 |
|-|-|-|-|
| 1 | 聚焦零位移 | 记录 `getBoundingClientRect()` 前后宽高 | 差值 = 0px；`layoutShift` 无 CLS 记录 |
| 2 | 双环参数 | 读 computed `box-shadow` | 恰为 `0 0 0 1px accent, 0 0 0 4px glow`；过渡 120~180ms |
| 3 | 层级 | 用取色器量相邻两层 | 明度差落在 1.5%~3.0%；全页无 ≥2px 边框 |
| 4 | 暗色字重 | 读 computed `font-weight` | 正文 400、说明 400、标题 ≤600；浅色对应为 500/500/600 |
| 5 | 对比度 | 最差底色下计算 | primary ≥12:1，secondary ≥7:1，tertiary ≥4.5:1 |
| 6 | 打字动画总时长 | `Performance.now()` 量首字起点→末字结束 | ≤600ms；字数 ≤8 时错开 20~40ms |
| 7 | 打字动画形态 | 抽帧观察 | 起手 blur 4~6px、终点 blur 0；`translateY` ≤2px；文字与图标基线不漂 |
| 8 | 数字稳定性 | 计时器连拍 10 帧，量文本宽度 | 字符 advance 变化 = 0px；`tabular-nums` 生效 |
| 9 | 拖拽咬合 | 量 pointerdown→首帧位移 | ≤1 帧（16.7ms）；拖动期间 `transform` 与指针差 ≤1px |
| 10 | 回弹过冲 | 采样 `transform` 极值 | ≤4px（实现 2px）；无惯性拖尾（松手后无继续位移） |
| 11 | Toast | 秒表 | 2500ms ±100ms 自动消失；点 × 立即消失 |
| 12 | 减少动态 | 系统开启 reduce + 页面 `[data-motion="off"]` | 无位移、无模糊，文字首帧完整；Toast 直接淡出 |
| 13 | 中文排版 | 缩窄容器到 30 字符宽 | 末行无单字；标点不在行首；表格无 1 字宽单元格 |
| 14 | 可读性底线 | 关闭动效后通读 | 所有动效均可省略而不损失信息 |

## 5. 已落地到 Chat2Todo（Qt / QSS）

看板与设置页已按本文档改造，实现在：

| 文件 | 承担 |
|-|-|
| [theme.py](../../src/chat2todo/qt/widgets/theme.py) | 全部颜色令牌、字重令牌、`mix()` 插值、`tabular()` 等宽数字 |
| [focus_ring.py](../../src/chat2todo/qt/widgets/focus_ring.py) | 输入框外环柔光（`QGraphicsDropShadowEffect`），聚焦进出自动开关 |
| [card.py](../../src/chat2todo/qt/widgets/card.py) | 卡片自绘：微阴影 + 双环聚焦 + hover 只提透明度 |
| [dashboard.py](../../src/chat2todo/qt/dashboard.py) | 标题/说明/时钟字体改用令牌；两个输入框挂柔光 |
| [settings_panel.py](../../src/chat2todo/qt/settings_panel.py) | 输入框与数字框统一细线 + 聚焦换色 + 柔光 |

| Web | Qt 实现 | 落地细节 |
|-|-|-|
| `box-shadow` 双环 | 内环 = QSS 边框恒 1px 只换色；外环 = `QGraphicsDropShadowEffect`(offset 0, blur 10, 30% 主色) | 一个控件只能挂一个 effect，所以内环必须用边框而不是第二个 shadow |
| `border-radius` | QSS `border-radius` + 自绘卡片 | QSS 圆角不裁剪子控件，卡片走 `paintEvent` 自绘 |
| `font-variant-numeric` | `QFont.setFamilies(["Consolas", "Microsoft YaHei UI"])` + `setFeature(tnum)` | 实测雅黑 UI 的 0-9 步进本身都是 8px，已天然等宽；Consolas 兜底 + tnum 双保险 |
| 字重 400/550 | `QFont.Weight` 枚举映射 | Qt 没有 550 档，`qt_weight()` 落到 DemiBold(600)，仍在规范上限内 |
| hover 微亮 | 细线 alpha 7% → 12%，RGB 不变 | 早期实现是掺 18% 主色，实测 alpha 会翻三倍变成"绿描边"，已改掉 |
| `prefers-reduced-motion` | 尚未接入 | 桌面端动效本就很轻（滚动动画可关），未做系统级联动 |

回归测试：[test_qt_theme.py](../../tests/test_qt_theme.py)（对比度、明度差、字重、数字等于宽）、
[test_qt_focus_ring.py](../../tests/test_qt_focus_ring.py)（聚焦环开关、零尺寸变化、hover 不许变彩色描边）。

当前桌面端看板的材质（Mica / 亚克力 / 纯色）与本文档的"微明度"是同一套思路的两条实现路径：**材质负责背景，微明度负责内容层级**，两者不叠加使用同一层级的阴影。
