# Win11 兼容性验收清单

> 适用范围：Chat2Todo 桌面端（PySide6 版，`c2t dash` / `chat2todo_qt.exe`）。
> 承诺平台：**Windows 11 22H2 及以上**。Win10 可运行但材质与吸附行为不做验收承诺。
>
> 本文既是验收清单，也是「出问题先查这里」的对照表。每项给出：验证方法 / 期望结果 / 降级行为。

## 一、材质与外观（亚克力降级链）

看板窗口按 DWM 能力**三级降级**，代码在 `qt/main_window.py::_apply_material` + `qt/dwm.py`：

| 级别 | 调用 | 成功判据 | 外观 |
|---|---|---|---|
| 1 | `DwmSetWindowAttribute(DWMWA_SYSTEMBACKDROP_TYPE=38, kind=3)` | API 返回 `S_OK` | Mica Alt 系统材质，跟随桌面壁纸与主题 |
| 2 | `SetWindowCompositionAttribute(属性 30 + AccentState=3)` | 返回非零 | 亚克力模糊，tint `0x80292929`（附亮度开关） |
| 3 | 纯色绘制 `alpha=150` | 前两级都失败 | 半透明深色底，无模糊，功能完整 |

**验证方法**

1. 打开看板，观察背板是否透出桌面模糊 → 是则为 1 级或 2 级
2. 拖到纯色壁纸与复杂壁纸各看一次，模糊应跟随变化
3. 关掉 `[dash] material = false` 重启 → 应立即变纯色底，且不报错

**已知降级触发条件**

- 关闭了「透明效果」（设置 → 辅助功能 → 视觉效果）→ 系统强制纯色，属预期
- 远程桌面 / 部分虚拟机（无 DWM 合成）→ 落到 3 级
- 显卡驱动异常或 DWM 崩溃恢复后 → 落到 3 级，重启程序即恢复

**降级安全性**：三级都只影响观感。文字、勾选、滚动、右键菜单在三级下行为完全一致，不存在「材质失败导致点不动」的情况。

## 二、吸附与多显示器

| 项 | 验证 | 期望 |
|---|---|---|
| 顶部吸附 | 拖到屏幕顶端 | 不满意 `WM_NCHITTEST` → `HTMAXBUTTON`，出现系统贴边布局预览并吸附 |
| 贴边收起 | 拖到左右边缘停住 | 自动半收起，鼠标移入展开 |
| 多显示器 | 显示器 1 上看板，拔掉显示器 2 后重启 | 窗口回到主屏可见区域，不跑到屏幕外 |
| 缩放比例 | 125% / 150% / 200% 各跑一次 | 文字不裁切（`PassThrough` 策略 + `setPointSize`） |

## 三、焦点与窗口行为

| 项 | 验证 | 期望 |
|---|---|---|
| 不抢焦点 | 看板置顶时在其它程序里输入 | 输入不被打断（`WS_EX_NOACTIVATE`） |
| 需要输入时临时激活 | 点击卡片上的「改」按钮 | 该瞬间允许激活，失焦后自动恢复不抢焦点 |
| 截屏隐藏 | 开启 `exclude_from_capture` 后用 Win+Shift+S 截图 | 看板不出现在截图里（`WDA_EXCLUDEFROMCAPTURE`） |
| 单实例 | 连点两次桌面图标 | 第二次静默退出，不出现两个看板 |

## 四、采集通道

| 项 | 验证 | 期望 |
|---|---|---|
| UIA 主路径 | QQ 开着、聊天窗口可见时触发采集 | 正常取到消息 |
| OCR 兜底 | 手动改坏 `uia_selectors` 里的选择器 | 自动降级到 Win11 系统 OCR，界面提示当前引擎 |
| 截图仅内存 | 关闭「截图归档」后截图建待办 | 磁盘任何位置都不新增 png（临时图只在内存） |
| 只读约束 | 全程观察 QQ | 不写 QQ 库、不注入进程、不改 QQ 设置 |
